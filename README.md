# 🚀 Premium Feedback System

Современное Fullstack-приложение для системы отзывов и комментариев, построенное на базе **FastAPI**, **SQLAlchemy** и **Bootstrap 5**.

## ✨ Особенности проекта
- **Интерактивный интерфейс**: Плавные анимации, "стеклянный" дизайн (Glassmorphism) и адаптивная верстка.
- **Умный поиск**: Реализован регистронезависимый поиск по комментариям с полной поддержкой кириллицы (находит слова независимо от размера букв).
- **Система рейтинга**: Возможность ставить лайки и дизлайки в реальном времени.
- **Топ дня**: Автоматическое выделение самого популярного комментария специальной короной 👑 и золотистым градиентом.
- **Безопасность**: Защита от отправки пустых сообщений и базовое предотвращение дубликатов (спама).

## 🛠 Технологический стек
- **Backend**: Python 3.10+, FastAPI.
- **Database**: SQLite + SQLAlchemy (ORM).
- **Frontend**: HTML5, CSS3, JavaScript (Fetch API).
- **Стили**: Bootstrap 5 + Custom CSS.
